# Списки сообщества ZapretXmel

Эта ветка — каталог готовых списков доменов для
[ZapretXmel](https://github.com/igorxmel/ZapretXmel). Программа читает его в разделе
«Списки» → «Каталог сообщества» и добавляет выбранный список к вашим записям: сначала
в редактор, а сохраняете вы сами.

Списки здесь — только данные: домены, по одному на строку. Никаких
программ и скриптов в каталоге нет и быть не может.

## Как добавить свой список

1. Сделайте форк репозитория и переключитесь на ветку `community-lists`.
2. Положите файл в `lists/` — имя латиницей, через дефис, например `lists/riot-games.txt`.
   Внутри по домену на строку (`example.com`), строки с `#` — комментарии.
3. Добавьте описание в `index.json`:

   ```json
   {
     "id": "riot-games",
     "title": "Riot Games: Valorant, League of Legends",
     "description": "Лаунчер, вход и обновления. Проверено на Ростелекоме в ноябре 2026.",
     "author": "ваш ник на GitHub",
     "kind": "domain",
     "file": "lists/riot-games.txt"
   }
   ```

   `kind` — `domain` (сайты, которые нужно пропускать через обход) или `exclude` (сайты,
   которые обход трогать не должен). `id` совпадает с именем файла без `.txt`.
4. Откройте pull request **в ветку `community-lists`**, а не в `main`.

Проверка в pull request'е сама сверит формат: что файл есть, записи похожи на домены, `id` не повторяется. После неё список смотрит автор проекта и принимает его, если
он понятен и полезен.

## Что не примут

- рекламные, фишинговые и прочие сомнительные домены;
- списки «всего подряд» без понятного назначения;
- чужие списки без указания, откуда они взяты.
