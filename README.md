# Оболочки ZapretXmel

Эта ветка хранит каталог оболочек и пример «Пульт». Оболочка рисует интерфейс на
HTML, CSS и JavaScript и обращается к ZapretXmel через UI API v1.
В примере команды и обработка ответов показаны в console/app.js.

## Как предложить оболочку

1. Создайте форк и заведите ветку от `community-ui`. Возьмите папку `console`
   за пример и дайте своей оболочке уникальный идентификатор.
2. Положите ресурсы в папку с этим идентификатором. Входная страница называется
   `index.html`. Поддерживаются HTML, CSS, JavaScript, PNG и WebP. До 40 файлов
   и 2 МиБ на пакет. Используйте локальные ресурсы и относительные ссылки.
3. Укажите в `manifest.json` поля `id`, `title`, `version` и `api`.
   В объекте `files` перечислите файлы с их SHA‑256. Добавьте в `packages`
   файла `catalog.json` идентификатор пакета и SHA‑256 его манифеста. В Windows
   хеш файла выдаёт `Get-FileHash -Algorithm SHA256 <путь>`. Используйте
   строчные шестнадцатеричные символы.
4. Запустите `python tools/check_catalog.py .`. Затем откройте pull request
   в `community-ui`, приложите снимок интерфейса и коротко опишите, какие
   действия можно выполнить.

Проверка CI сверяет формат, совместимость и хеши. В pull request используется
проверяющий скрипт из базового коммита. Автор проекта отдельно просматривает
интерфейс и JavaScript перед включением в каталог.
