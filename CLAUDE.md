# ZapretXmel

**Правила проекта — в [AGENTS.md](AGENTS.md). Прочитайте его целиком перед
тем, как что-то менять.**

Два файла вместо одного не ради красоты. Claude Code подхватывает `CLAUDE.md`
сам, а `AGENTS.md` читают остальные помощники — OpenCode, Codex и прочие.
Держать в двух местах одно и то же нельзя: копии разойдутся молча, и половина
агентов будет работать по устаревшим правилам. Поэтому содержимое живёт в
одном файле, а здесь только указатель на него.
